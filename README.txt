NEXORA V3 FIXED
=================
1. Keep index.html, style.css and script.js in the SAME folder.
2. Open index.html in Chrome/Edge/Firefox.
3. Create an account or use "Continue with demo account".
4. On mobile, use the bottom navigation.
5. The four Home cards are now real buttons and open their sections.
6. Code Lab runs HTML/CSS/JavaScript in the browser.
7. Resume Print lets you choose "Save as PDF".
8. Data is stored in localStorage on this browser.

IMPORTANT:
- This is an offline frontend. Real Google OAuth, cloud database/sync,
  AI generation, and server-side C/C++/Java/Python compilation require a backend.
- Do not separate the three files when opening the website.
